# Cream Canvas Brand Story

Build a polished, modern minimalist personal portfolio website for a professional brand strategist. Implement the full working responsive site, not just a mockup. Visual direction: warm cream #FFFEF9 background, deep ink #1a1a1a, vivid magenta #FF1493 accent and cyan #00CED1 tags. Editorial Swiss-inspired grid, oversized ultra-bold sans typography, generous whitespace, thin dividers, sophisticated motion, strong responsive behavior. Hero has large two-line placeholder name “YOUR NAME”, oversized pink title “Brand Strategist”, circular portrait with vibrant gradient ring (use a tasteful remote portrait placeholder or abstract editorial portrait), eyebrow/tag, short mission statement. Header has minimal monogram, responsive navigation with mobile menu. Sections: About bio mentioning a decade of experience, strategy and storytelling (clearly mark sample copy as editable placeholder); contact links with placeholder email/phone/website; experience timeline with role, dates, detailed impact-led descriptions and metrics such as 200% growth, but label metrics and brand names as sample placeholders rather than fabricated verified claims; education; skills and languages in categorized grid/tag blocks; selected work/approach section if it improves story; CTA and footer. Do not imply real affiliations with well-known brands—use clearly editable placeholder client names such as [Client Name]. Include accessible semantic HTML, keyboard-accessible controls, reduced-motion support, SEO metadata, smooth anchor scrolling, animated link underline/color hover, subtle reveal/loading animation that does not delay access to content, and black circular back-to-top button. Use maintainable React + TypeScript + Tailwind and shadcn/ui where useful. Provide complete implementation in project files. Ensure no dead links, mobile layout works, and contact details are editable placeholders. Give the site a distinctive art-directed design rather than generic template styling.
